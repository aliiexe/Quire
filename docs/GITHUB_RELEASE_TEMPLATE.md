# Quire 0.2.6 — Review the writing before it lands

Quire is a free, open-source, local-first workspace for writing and compiling LaTeX on your Mac. Your projects, PDFs, and builds stay on your computer—there is no account, cloud workspace, remote compiler, analytics, or paid tier.

## What’s new in 0.2.6

- **Review source and PDF together** — Quire Draft now compiles each proposed change in a private temporary copy. Before you decide, the editor highlights the proposed source and the PDF panel shows the matching compiled document. Your real files and existing PDF stay untouched until **Apply**.
- **Clear Draft feedback** — A working state appears while your request is being prepared. When it is ready, Quire Draft confirms it and moves you to the result; the workspace then reports when the temporary PDF is ready to review.
- **A Files sidebar you can always reopen** — Collapsing the file explorer now leaves a persistent **Files** button in the workspace, so it never becomes inaccessible.
- **Native text actions plus Quire Draft** — Right-click selected text for the usual macOS editing actions and **Send selection to Quire Draft**.

## Download

- **Apple Silicon** (M1, M2, M3, M4, and newer): download `Quire-0.2.6-arm64.dmg`.
- **Intel Mac**: download `Quire-0.2.6-x64.dmg`.

## Install Quire

1. Open the downloaded DMG.
2. Drag **Quire.app** into the **Applications** folder.
3. Open Quire from Applications.

### First-launch note

Quire is an independent, free, open-source macOS preview and is not yet Apple-notarized. macOS may block the first launch because it cannot yet verify the developer.

If that happens, try opening Quire once, then open **System Settings → Privacy & Security** and choose **Open Anyway** for Quire. Confirm the next prompt. You only need to do this once.

## Privacy and support

Quire works locally on your Mac. Quire Draft is off until you configure your own provider API key and deliberately send it selected text or a writing brief. Read the privacy policy at https://quire-app.vercel.app/privacy.
