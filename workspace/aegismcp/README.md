# Rapport AegisMCP - sources LaTeX

**Auteurs :** Ali Bourak et Younes Tarik  
**Année universitaire :** 2026-2027

## Compilation

Le projet est compatible avec une installation LaTeX standard/Overleaf.

```bash
latexmk -pdf main.tex
```

ou :

```bash
pdflatex main.tex
pdflatex main.tex
```

Le fichier principal est `main.tex`; le contenu est réparti dans `chapitres/`.

## Remarques

- Remplacer les champs `À compléter` de la page de garde par le nom de l'établissement et de l'encadrant(e).
- Le chapitre 5 distingue explicitement les résultats réellement observés des modules et évaluations encore planifiés; aucun résultat expérimental non mesuré n'a été inventé.
